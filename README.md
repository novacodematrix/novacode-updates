# NovaCode Updateinformationen

Öffentliche Updatekanäle für die vier NovaCode Team Windows-Apps. Dieses Repository enthält ausschließlich Updateinformationen. Programmcode bleibt privat. Keine Installer, Schlüssel oder Kundendaten werden hier veröffentlicht.

## Feste HTTPS-Adressen

- Business: https://novacodematrix.github.io/novacode-updates/business.xml
- Office Dialer: https://novacodematrix.github.io/novacode-updates/dialer.xml
- Matrix: https://novacodematrix.github.io/novacode-updates/matrix.xml
- Service: https://novacodematrix.github.io/novacode-updates/service.xml

Die RSS-Appcasts enthalten derzeit keine Updateeinträge. Es ist keine neue Version zur Installation freigegeben. Für jedes Produkt wird nur dessen eigener Kanal verwendet. Die Dateien werden kostenlos über GitHub Pages aus diesem öffentlichen Repository bereitgestellt. Keine zusätzlichen Konten, kostenpflichtigen Dienste oder eigenen Domains eingerichtet.

## Aktivierung und spätere Freigabe

Die Adressen allein aktivieren keinen Updater. Die installierten Apps benötigen die passende lokale Vertrauenskonfiguration einschließlich des echten öffentlichen Ed25519-Prüfschlüssels. Dieser Schlüssel wird gemäß Auftrag hier nicht veröffentlicht. Private Signierschlüssel gehören niemals in dieses Repository oder in Kundenpakete.

Erst nach separater Freigabe, abschließender Prüfung und Signierung darf ein Updateeintrag mit passender Produktversion, Windows-Installeradresse, Dateigröße und gültiger Update-Signatur ergänzt werden. Ein Eintrag ohne herunterladbaren und geprüften Installer wird nicht veröffentlicht. Windows-Appsignatur und Update-Signatur sind getrennt.

Der Team-Server wird weiterhin nach Dienststopp und Datensicherung manuell aktualisiert. Die Kanäle gelten ausschließlich für die vier Client-Apps.
