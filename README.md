# NovaCode Updateinformationen

Öffentliche Updatekanäle für die vier NovaCode Team Windows-Apps. Dieses Repository enthält ausschließlich Updateinformationen. Programmcode bleibt privat. Keine Installer, Schlüssel oder Kundendaten werden hier veröffentlicht.

## Feste HTTPS-Adressen

- Business: https://raw.githubusercontent.com/novacodematrix/novacode-updates/main/business.xml
- Office Dialer: https://raw.githubusercontent.com/novacodematrix/novacode-updates/main/dialer.xml
- Matrix: https://raw.githubusercontent.com/novacodematrix/novacode-updates/main/matrix.xml
- Service: https://raw.githubusercontent.com/novacodematrix/novacode-updates/main/service.xml

Die RSS-Appcasts enthalten derzeit keine Updateeinträge. Es ist keine neue Version zur Installation freigegeben. Die getrennten Kanäle verhindern die Vermischung der Produkte. GitHub stellt die Dateien direkt bereit; GitHub Pages, zusätzliche Dienste und kostenpflichtige Workflows werden nicht benötigt.

## Aktivierung und spätere Freigabe

Die erreichbaren Adressen allein aktivieren keinen Updater. Die installierten Apps benötigen die passende lokale Vertrauenskonfiguration einschließlich des echten öffentlichen Ed25519-Prüfschlüssels. Dieser Schlüssel wird gemäß Auftrag hier nicht veröffentlicht. Private Signierschlüssel gehören niemals in dieses Repository oder in Kundenpakete.

Erst nach separater Freigabe, abschließender Prüfung und Signierung darf ein Updateeintrag mit passender Produktversion, Windows-Installeradresse, Dateigröße und gültiger Update-Signatur ergänzt werden. Ein Eintrag ohne herunterladbaren und geprüften Installer wird nicht veröffentlicht. Windows-Appsignatur und Update-Signatur sind getrennt.

Der Team-Server wird weiterhin nach Dienststopp und Datensicherung manuell aktualisiert. Die Kanäle gelten ausschließlich für die vier Client-Apps.
